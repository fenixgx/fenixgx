AI-first productivity manager focused on conversational task management and proactive workflows.

Internal MCP-based system for persistent AI development context.

Nexus stores project memory, previous decisions, errors, code context, SPECs, and implementation notes so AI-assisted development sessions do not start from zero every time.

**Focus:** AI development workflow, project memory, structured SPECs, context persistence, implementation tracking.  
**Status:** Internal infrastructure.
